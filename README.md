# StellarAnalytics · Typecho 站点访问统计插件

记录站点访问数据（PV/UV/阅读时长/搜索词），后台独立报表页查看，爬虫与真人流量分离。

## ✨ 功能

- **访问记录**：PV / UV、访问页面、来源域名、浏览器/设备（UA）、时间；IP 仅存 SHA-256 前 24 位哈希（脱敏）
- **爬虫分离**：自动识别百度蜘蛛 / Googlebot / Bingbot 等爬虫，与真人流量分开统计（直接反映「百度来不来抓」）
- **文章阅读时长**：页面可见才累计（切后台暂停）、心跳上报、关页 sendBeacon，<5 秒不计——与百度统计/GA 同口径
- **站内搜索词**：记录访客在站内搜索的关键词，辅助选题
- **Top 报表**：Top 文章、Top 来源、近 14 天 PV/UV 趋势图
- **数据落库**：存入站点现有 SQLite（不引入新依赖），保留 90 天自动清理
- **防刷**：同 IP 同页面 60 秒去重

## 📦 安装

1. 将本仓库文件夹（`StellarAnalytics/`）放入 `usr/plugins/`，插件名 `StellarAnalytics`
2. 后台启用，顶栏出现「📊 访问统计」入口

## ⚙️ 配置

- 插件 → 设置：访问记录开关（关闭即停止埋点）

## 📊 报表页

后台顶栏「访问统计」进入：概览（今日/昨日/累计 PV·UV、爬虫访问、累计阅读时长）、近 14 天趋势、Top 文章、爬虫分类、Top 来源、搜索词 Top、最近访问明细。

## 🧩 兼容性

- Typecho 1.2+ / 1.3，PHP 7.4+，SQLite / MySQL
